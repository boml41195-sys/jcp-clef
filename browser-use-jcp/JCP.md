# JCP: estudo de aplicabilidade e MVP com Clef

O repositório Browser Use foi clonado para servir de base ao JCP. O estudo e a especificação do MVP ficam em [docs/jcp](docs/jcp/README.md).

Base inspecionada: `7be96ed8bafa8dfe1eef228b59cf5c884b8b2431`, versão declarada 0.13.10. O pivot usa Clef no módulo de decisões delimitadas. BrowserSession/Actor continuam responsáveis pela execução; um modelo generativo continua necessário para descoberta ou reparos que exijam construir um percurso novo.

Esta entrega contém o estudo baseado no código e a documentação de implementação. Não declara que o runtime JCP, a inferência Clef ou os conectores de tribunais já estejam operacionais.
